# Security Policy

Please report security issues privately to the repository owner rather than opening a public issue with exploit details.

Do not include access tokens, cookies, local account names, absolute user paths, WorkBuddy conversation content, or private screenshots in a report. A minimal reproduction with redacted logs is preferred.

This project does not require administrator rights and does not modify `app.asar`. Any build or fork that adds binary patching, credential extraction, unrestricted `file://` control, or system-update behavior is outside this project's supported security model.
